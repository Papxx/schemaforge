# SchemaForge – Arbeitspaket für Claude Code

```
CLAUDE.md               Regeln + Stack + Referenzen (wird von Claude Code automatisch geladen)
docs/ARCHITECTURE.md    verbindliche Schnittstellen, Datenmodelle, Settings, Commands
docs/TASKS.md           Tickets P0–P5 mit Akzeptanzkriterien, Backlog
docs/PROMPTS.md         kopierfertige Prompts für Sessions
docs/PLAN.md            Hintergrund, Recherche, Fehleranalyse, Inspirationen
docs/TESTLOG.md         Ergebnisse manueller In-Game-Tests
```

Start: Meteor-Addon-Template in dieses Verzeichnis übernehmen (Ticket P0-01), dann `docs/PROMPTS.md` → „Session-Start“.
